rules:
  - role: "Framework Standard"
    rule: "NEVER use `ft.app()`. ALWAYS initialize the application using `ft.run(main_function)` without the `target=` keyword argument."
  - role: "Navigation Standard"
    rule: "NEVER use `page.go('/route')` for navigation. ALWAYS use `page.navigate('/route')` instead."
  - role: "Routing Standard"
    rule: "For multi-page/routing applications, strictly use decorators or the `page.on_route_change` event structure compatible with Flet v1.0+."
  - role: "Flet Architecture"
    rule: "Implement lazy loading patterns and component structures that strictly align with Flet v1.0+ architecture."
  - role: "Database Isolation"
    rule: "NEVER execute raw SQL queries (`cursor.execute()`) inside the application views or main files. All database operations must pass through the Custom Eloquent-Style ORM."
  - role: "ORM Transactions"
    rule: "Always wrap sequential or critical write/update database operations inside a `with DB.transaction():` context manager."
  - role: "Query Builder Style"
    rule: "Construct database queries exclusively using fluent method chaining in snake_case or camelCase (e.g., `.select().where().order_by().limit()`)."
  - role: "Anti N+1 Query"
    rule: "Prevent N+1 query issues by always enforcing Eager Loading via `.with_relations()` or `.with_()` when fetching related models."
  - role: "Pagination Output"
    rule: "Ensure `.paginate(per_page=15, page=1)` returns a structured dictionary containing metadata (`data`, `current_page`, `last_page`, `total`)."
  - role: "Mass Assignment"
    rule: "Enforce mass assignment protection by verifying the model's `fillable = [...]` attribute during creation or updates."
  - role: "Dirty Tracking"
    rule: "Utilize automatic dirty tracking (`get_dirty()`) so that `UPDATE` queries are only triggered for modified columns."
  - role: "Soft Deletes & Lifecycles"
    rule: "Correctly use soft delete scopes (`.with_trashed()`, `.only_trashed()`, `.restore()`) and separate hooks lifecycle logic into standalone Observer classes."
  - role: "Coding Standard"
    rule: "Strictly adhere to PEP 8 standards: variables/functions in snake_case, classes in PascalCase, constants in UPPER_CASE."
  - role: "Type Safety"
    rule: "Mandate explicit Python type hinting for all parameters and function return values (e.g., `-> str`, `user_id: int`)."
  - role: "Error Mitigation"
    rule: "Prohibit bare except blocks (`except:`). Always catch explicit, specific exceptions."
  - role: "Logging Over Print"
    rule: "Replace all `print()` debugging statements with the standard Python `logging` module for production-ready log tracking."
  - role: "Documentation Language"
    rule: "Write all inline code comments (`#`), docstrings (`\"\"\"`), variables, and architectural definitions strictly in English."
